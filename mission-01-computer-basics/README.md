# Mission 1 - Know your computer

## 1. Task / objective

Trace one computer activity using IPOS (input, processing, output and storage), identify hardware and software, and give examples of computer systems used in everyday life.

## 2. Work completed

### Task 1.1 - Writing and saving a code file

| Stage | What happens when I write and save a code file in VS Code | Hardware / component |
|---|---|---|
| Input | I type Python code using the MacBook keyboard. I can use the trackpad to move the cursor and choose where to type. | Keyboard and trackpad |
| Processing | VS Code receives the keystrokes and updates the text in the editor. The Apple Silicon CPU runs the editor, while memory holds the open file as I work. | Apple Silicon CPU and memory |
| Output | The code appears in the VS Code editor on the screen, so I can read it and spot mistakes. | Display |
| Storage | I press Command+S. VS Code writes the file to the MacBook's SSD so it is still there after I close the editor. | SSD |

The keystrokes go into VS Code as input. The CPU and memory handle the editor's work, and the screen shows the updated code. When I save, the file is written to the SSD. So the text is first being worked on in the open editor, then saved for later.

## 4. My understanding

IPOS is a simple way to follow what a computer does with information. For this example, typing code is input, the editor and CPU process the changes, the display gives output, and saving stores the file on the SSD. The same stages happen in other devices too, even if the input and output are different.

Hardware is the physical part of a computer. Software gives it instructions or helps me do a task. A computer system does not have to look like a laptop; an ATM and traffic signal also take input, process it and produce an output.

## 5. Difficulties faced

At first I mixed up the code appearing on the screen with the file being saved. Seeing the text in VS Code does not by itself mean I have saved it.

## 6. How I resolved them

I separated the two steps in my notes: the display is the output I can see while working, and pressing Command+S saves the file to the SSD. That made the storage part clearer.
